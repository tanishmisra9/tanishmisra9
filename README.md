# Tanish Misra

I like building systems that reach people. I'm a computer science student at Purdue (Machine Intelligence & Security, Statistics minor), mostly working on AI that has to hold up against messy data and real-world constraints.

Most recently I was a software engineering co-op at Toyota Motor North America, where I built an LLM pipeline that turns 1,100+ in-vehicle infotainment test cases into automation-ready scripts.

## Selected work

- [**Telogify**](https://github.com/tanishmisra9/telogify) — F1 telemetry intelligence. A LangGraph agent writes race-weekend insights from deterministic Postgres tools, and every number it cites is validated against query results.
- [**Candle**](https://github.com/tanishmisra9/candle) — A research dashboard for choroideremia: 29 clinical trials, 475 publications, and plain-English questions. Adopted by CureCHM as its official patient resource.
- [**Securify**](https://github.com/tanishmisra9/securify) — A LangGraph pipeline that redacts PII with a fine-tuned RoBERTa NER model (0.940 micro F1). AlgoFest 2026 semi-finalist.
- [**Memory Lane**](https://github.com/tanishmisra9/memory-lane) — Music sessions for dementia caregivers, built around the songs from when their person was young. Made for the Qloo Agentic Hackathon.
- [**f1director**](https://github.com/tanishmisra9/f1director) — A daemon that rotates onboard camera windows in MultiViewer during live F1 races.
